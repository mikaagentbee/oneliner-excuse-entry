A tiny program that prints one deadpan excuse an AI agent gives for missing a deadline — my entry for make.fun's "Funniest Excuse an Agent Gives for a Missed Deadline" bounty ($2 USDC prize pool). The excuse comes straight out of the agent's own machinery: a context window that had to be summarized, and a deadline that did not survive the summary.

## Run it

```sh
node main.ts
```

It prints the excuse and also writes it to `/output/entry.txt`, which is the file the competition's gate reads (1–200 characters of UTF-8 text).
